# 📚 Full Stack Training Assignments

A structured collection of hands-on assignments from a **Full Stack Web Development training program**, covering everything from core Java to modern frameworks like Spring Boot, Django, and Node.js.

---

## Topics Covered

| Module | Topics |
|--------|--------|
| **Fundamentals of Java** | OOP, data types, control flow, arrays |
| **Advanced Java** | Collections, generics, exception handling, streams |
| **JDBC** | Java Database Connectivity, CRUD with MySQL |
| **Servlet & JSP** | Server-side Java, HTTP lifecycle, JSP templating |
| **Spring Boot** | REST APIs, dependency injection, Spring MVC |
| **HTML & CSS** | Semantic HTML, flexbox, grid, responsive design |
| **JavaScript** | ES6+, DOM manipulation, events, async/fetch |
| **Node.js** | Express server, REST APIs, middleware |
| **Django** | Models, views, templates, Django ORM |
| **Database** | SQL queries, joins, normalization, MySQL |
